# Dependências de terceiros

Os JARs em `target/dependency/` são dependências de execução distribuídas com seus metadados de licença no próprio arquivo JAR. Consulte `META-INF/LICENSE*` e `META-INF/NOTICE*` em cada um.

- Apache Tomcat 10.1.50 — Apache License 2.0.
- Eclipse JDT ECJ (compilador JSP transitivo) — Eclipse Public License 2.0.
- H2 Database 2.3.232 — licenciamento duplo MPL 2.0 / EPL 1.0, conforme metadados da distribuição.
- Testes: JUnit Jupiter 5.11.4 e dependências Maven; não fazem parte do runtime copiado.

As versões das dependências constam do pom.xml e dos nomes dos JARs. Os pôsteres dos filmes são imagens de divulgação de seus respectivos titulares; suas fontes e arquivos estão documentados em docs/FONTES-CAPAS.md. Não há necessidade de API externa para exibir as capas depois de baixar o projeto.
